# AegisMesh

> Multi-agent security platform for AI-agent risks — each risk item of the "Security Risks in AI Agents" diagram is defended by exactly one independent agent, and every verdict lands in an append-only evidence ledger.
> 한국어: [README.md](README.md) · Source requirements: `.docs/AegisMesh_PRD.pdf`, `.docs/AegisMesh_UI_Design.pdf` · Compliance overlay: [COMPLIANCE.md](COMPLIANCE.md)

## Quick start

```bash
make preflight
make local-all                                   # api + web (first start migrates and seeds)
curl http://127.0.0.1:8000/health
make local-logs | grep 부트스트랩                  # first-run one-time token (24h) — lost? make admin-token
open http://127.0.0.1:3000/setup                 # first run: break-glass admin + first tenant → sign in
TOKEN=$(curl -s http://127.0.0.1:8000/v1/auth/login -H 'content-type: application/json' \
        -d '{"username":"<id>","password":"<pw>"}' | jq -r .token)
curl -X POST http://127.0.0.1:8000/v1/profiles/tool-agent:apply -H "Authorization: Bearer $TOKEN" \
     -H 'content-type: application/json' -d '{"target":"agent.example"}'
make test && make test-web && make coverage
make local-stop
```

Prod rehearsal: `cp .env.example .env.prod` (replace CHANGE_ME) → `make local-stop` → `make prod-build` → `make db-migrate ENV=prod && make db-seed ENV=prod && make db-ping ENV=prod` → `make admin-token ENV=prod` (bootstrap token → console `/setup`) → `make prod-stop`.

Run 10 decisions: ledger plaintext is removed by **controlled re-encryption** (two-person approval, a signed certificate and an expiring window; only inside it does the DB trigger allow plaintext → ciphertext with every other column unchanged; the hash chain stays). OQ5 (columnar evidence store) and OQ6 (external policy engine) stay as they are, with switch conditions recorded. The inline model is an English-trained pinned release, so only Latin-script input is sent; deployment uses `ENGINE_OVERRIDES`. L2 runs gVisor as a compose broker (no Docker daemon changes); only seccomp and AppArmor are unconfined. agentgateway connects through an ExtMCP (gRPC) policy server (local). The HSM path is rehearsed with SoftHSM2 (a real HSM changes only the library and token). 2,000 rps hit the shared-VM measurement limit — per the BLOCKED answer, the best 1,797 rps is accepted as the rehearsal figure and confirmation moves to a dedicated node.

Run 9 decisions: after a deep-check alert the **session is quarantined** (the next request from the same principal or session is blocked inline; release by two people, 1-hour expiry). Geo-IP (DB-IP Lite, CC BY 4.0) and FIDO MDS3 are **pinned at image build**. The MDS3 BLOB changes monthly at the same URL, so instead of a hash pin the FIDO signature chain (GlobalSign Root CA - R3 fingerprint, signer name, CRL) is the pin and a verification failure fails the build. Only the packed (x5c) attestation format is supported; tenants without an allowlist keep possession-only passkeys (only models MDS reports as compromised or bypassable are refused). Impossible travel alerts and re-authenticates, it does not block. OpenBao uses a same-host transit unsealer plus a 3-node raft cluster in the prod rehearsal; the at-rest KEK stays where it was. English CLI covers human-readable lines and help (JSON stays as is).
