# 65th — L2 격리 gVisor (Epic 65 · NFR-I · FR-P08 · OQ2 · 9차 한계 'L2·L3 런타임 없음')

근거: 격리 등급 L2(사용자 공간 커널)를 요구하는 서드파티 에이전트는 런타임이 없어 심사 R4 에서 보류됐다(38th). Docker Desktop 데몬
설정은 바꿀 수 없으므로(호스트 설정 금지) gVisor `runsc` 를 compose 서비스 안에서 돌리는 브로커로 L2 를 만든다. L3(microVM)는 KVM 없음 — 범위 밖.

| id | 목적 | 입력 | 기대 | 우선 |
|----|------|------|------|------|
| C01 | 고정 판 런타임 | `make l2-up` | runsc 판·아키텍처별 묶음 sha256 고정 이미지 빌드, 준비 = 실제 샌드박스 커널이 gVisor | P0 |
| C02 | 최소 권한 브로커 | compose 정의·실행 | 비루트·능력 없음·새 권한 금지·읽기 전용, 브로커 비밀(/tls)·번들 목록은 샌드박스 밖 | P0 |
| C03 | 심사 R4 를 L2 에서 | L2 요구 서드파티 번들 등록 | 골든·공격 재생이 L2 샌드박스에서, L3 없음 → 경보 전용(OQ2) | P0 |
| C04 | 관문 판정을 L2 에서 | `POST /v1/judge?agent=x10` | 브로커 경유 판정·근거, 강등 없음, 웜 지연 실측 | P0 |
| C05 | 탈출 점검 | `POST /v1/sandbox:probe?level=L2` | gVisor 경계(커널·네트워크·밖 파일·프로세스·덧씌움) + 안쪽 잠금 층 전부 막힘, 원장 기록 | P0 |
| C06 | 에이전트 코드의 우회 시도 | 네트워크·ctypes·하위 프로세스·키 읽기·/proc·무한 루프 | 모두 막힘, 루프는 시간 초과 → 회수 | P0 |
| C07 | 격리 강등 금지 | 브로커 고갈·중단(가짜 브로커) | 강등(failMode)·기동 거부, L1 로 대신 돌리지 않음 | P0 |
| C08 | 회귀·계약 | `make test` · `make contract-update` | 전부 통과, probe `level` 반영 | P0 |
