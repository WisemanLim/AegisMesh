# 58th — 고정 판 갱신 자동화 (Epic 58 · 9차 한계)

근거: 54·55 의 외부 참조 데이터(FIDO MDS3·DB-IP Lite)는 이미지 빌드 고정 판 — 월간 갱신은 수동이었고 낡아도 알 수 없었다.

| id | 목적 | 입력 | 기대 | 우선 |
|----|------|------|------|------|
| C01 | 단위 회귀 | `make test` | 전부 통과 (test_pins: 다음 판 정하기·지금 판 재다운로드 없음·MDS nextUpdate 지나면 판 이름 변경, 전역 ARG 만 고쳐 쓰기·형식 오류 거부, MDS 캐시 판 일치, 낡음 점검 → worker 원장 → 알림·업데이트 API) | P0 |
| C02 | 갱신 실행 | `make pins-refresh` | 이미지 빌드 안에서만 네트워크, 지금 판이 최신이면 변경 0 | P0 |
| C03 | 다음 판 해석 | 옛 판(2026-09) 가정 빌드 | 실제 서버에서 2026-10 판·sha256(고정값과 같음) | P0 |
| C04 | 실행 중 점검 | worker pins 작업 | MDS3 no 290 다음 갱신 2026-11-01·DB-IP 7일 = 최신, 원장 pins_checked | P1 |
| C05 | MDS 요청 절약 | 바뀐 mds 스테이지 재빌드 | 같은 판 캐시 사본(`source: cache`) — MDS 요청 0 | P0 |
