# 시험 시나리오 / Test Scenario — impl 45th (Epic 45 확대·재배치 접근성)
- 근거: PRD.md §7 가정 "KWCAG 2.2 / WCAG 2.2 AA" — 1.4.4 글자 크기 조정(200%) · 1.4.10 재배치(320 CSS px = 1280px 화면 400% 확대) · 1.4.12 글자 간격. 39차 남은 것(확대·재배치 수동 점검 대상).
- 상충: 화면설계서 "최소 폭 1280px"(UI p.19) ↔ 1.4.10. 결정: 1024px 이상은 화면설계서 셸 그대로, 그보다 좁으면 메뉴를 접고 한 줄로 흐른다(설계서의 데스크톱 화면은 바뀌지 않음).
- 방식(`make e2e-a11y` ko 회차, 쪽마다): ① 뷰포트 320px 에서 문서 가로 스크롤 없음 — 표·코드·2차원 배치(`data-2d`)를 담은 스크롤 영역만 예외, 그 밖의 내용이 스크롤 영역에서 넘치면 실패 ② 1.4.12 글자 간격(줄 1.5·자간 0.12em·단어 0.16em·문단 2em) 적용 뒤 overflow hidden/clip 요소의 잘림 0(말줄임+title 은 경고) ③ 글자 200%(루트 글자 크기 2배) 뒤 잘림 0.
- 환경: local compose · plat.admin · 전 경로(74 틀)
