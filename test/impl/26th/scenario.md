# 시험 시나리오 / Test Scenario — impl 26th (Epic 26 콘솔 본문·보고서 영어)
- 근거: NFR-C4(콘솔·보고서 한국어·영어 동시 지원) — 19th 에서 화면 제목·메뉴만 병기, 본문·보고서는 한국어였다.
- 방식: 한국어 원문을 메시지 ID 로 쓰는 gettext 방식 `L(lang, "원문", …인자)` + 영어 카탈로그(lib/en.ts). TypeScript AST 코드모드로 표시 위치(JSX 텍스트·표시 속성·JSX 자식 문자열·템플릿·서버 액션 메시지)를 감싸고, API 값 표시 자리는 `LX(lang, v)`(문자열만 번역). 서버 렌더에서 번역(깜박임 없음), 클라이언트 컴포넌트는 LangProvider.
- 환경: local compose + 헤드리스 Chromium(쿠키 lang=en/ko)
