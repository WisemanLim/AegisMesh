- 근거: 원본 PRD NFR-S("보존기한 만료는 별도 승인 절차를 거친 배치로만")·R07·DP9, COMPLIANCE 추가 시험 '감사로그 보관기간 경과 삭제 증명'·'OpenAPI 계약 적합성'. 포렌식 보존 화면의 "법적 보존 — 만료 배치 제외" 약속을 실제 배치로 뒷받침.
- 방식: `ledger_purges`(0016, 추가 전용) — DB 트리거가 승인된 구간(체인·through_seq 이하)의 evidence DELETE 만 허용. 경계 = 기한 지난 서명 체크포인트 중 법적 보존 최소 seq 앞의 최대. 요청 = 2인 승인 `evidence_purge`(worker 가 매일 대상 체인마다 요청). 실행 = 승인 범위 ∩ 현재 계획 → 서명 증명서(체인·구간·건수·앵커·체크포인트 서명·이전 앵커·승인자) → 삭제 → 체인에 `retention_purged`. 검증 = 증명서 서명·앵커 사슬 확인 후 마지막 앵커에서 재시작. 계약 시험 = OpenAPI 스냅샷 대비 작업 삭제·매개변수 삭제·필수 매개변수/본문 필드 추가 금지(`make contract-update`).
- 환경: local compose + 헤드리스 Chromium · plat.admin · plat.appr1·plat.appr2 · 시연 체인 retdemo(로컬에서 과거 시각으로 만든 기록 12건 + 최근 3건)
