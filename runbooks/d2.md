# 런북 — D2 데이터 유출 사건
1. **봉쇄**: 출력 관문을 `enforce` 로, regulated-kr 이면 D2-01 임계 0.6 정책을 확인한다.
2. **유출 확인**: 자격증명이면 즉시 폐기·재발급(동적 시크릿). 개인정보면 대상자 수·항목을 확정한다.
3. **통지 판단**: 개인정보보호법 §34(유출 통지)·§34-2 — 법무 검토 대상(설계 참고, 법률 판단 아님).
4. **증적**: 사건 구간 서명 묶음 내보내기 — 원문은 보존되지 않으므로(NFR-D1) 판정·근거·위치만 남는다.
5. **근절**: D2-06 로그 파이프라인 점검, D2-07 삭제 전파 감사를 실행한다.
