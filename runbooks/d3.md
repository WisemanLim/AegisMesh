# 런북 — D3 도구 오남용 사건
1. **봉쇄**: 해당 에이전트를 격리 목록에 올리거나(`kind=agent`) 도구 허용목록에서 문제 도구를 뺀다.
2. **실행 여부 확인**: 도구 관문 판정이 block 이면 실행되지 않았다. require_approval 이면 승인함 기록을 확인한다.
3. **영향 평가**: 실행된 경우 샌드박스 로그·대상 시스템 감사 로그를 대조한다.
4. **근절**: 권한 범위(D3-06)·과업 범위 계약(D6-04)을 좁힌다.
5. **증적·회고**: 서명 묶음 내보내기, 공격 입력을 시험셋에 추가.
