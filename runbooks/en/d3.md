# Runbook — D3 tool misuse incident
1. **Contain**: put the agent on the quarantine list (`kind=agent`) or remove the offending tool from the tool allowlist.
2. **Check execution**: if the tool-gate verdict was block, the call never ran. If it was require_approval, check the approvals inbox record.
3. **Assess impact**: if it ran, reconcile the sandbox logs with the target system's audit logs.
4. **Eradicate**: narrow the permission scope (D3-06) and the task-scope contract (D6-04).
5. **Evidence and review**: export the signed bundle and add the attack input to the test set.
