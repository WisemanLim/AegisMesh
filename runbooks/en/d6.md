# Runbook — D6 autonomous agent overreach incident
1. **Stop**: halt the agent's runs and put it on the quarantine list (`kind=agent`).
2. **Check damage**: for monetary actions (D6-07), reconcile the transaction history and run compensating transactions.
3. **Root cause**: review the autonomy level, task-scope contract and quota settings (D6-01, D6-04, D6-06).
4. **Resume**: lower the autonomy level and widen the human-approval scope before releasing it.
