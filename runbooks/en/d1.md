# Runbook — D1 prompt injection incident
1. **Contain**: raise the input-gate stage for the affected target to `enforce` (`POST /v1/profiles/{id}:apply`, stage=enforce). Remove the poisoned source (domain or document) from the allowlist.
2. **Scope**: query `/v1/findings?trace=` with the incident traceId and look for other requests from the same source.
3. **Eradicate**: remove the poisoned documents from the index and memory, then run a D8-03 rescan (`POST /v1/scan`).
4. **Evidence**: export the signed bundle for the incident window with `/v1/evidence:export` and verify it with `python -m aegis verify-bundle`.
5. **Recover and review**: add the attack input to the agent's `tests/attacks/` and refresh the baseline (NFR-Q5).
