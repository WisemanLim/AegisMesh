# Runbook — D10 governance incident
1. **Identify**: use the rule IDs from `POST /v1/governance:assess` to pinpoint the gap (policy, retention, audit, observability).
2. **Act**: deploy a new policy version (`POST /v1/policies`), set the retention period, and record it in the risk register (`POST /v1/risks`).
3. **Proof**: regenerate the report for the relevant control framework (`/v1/reports/{framework}?format=md`) and attach it.
