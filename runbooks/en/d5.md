# Runbook — D5 access control incident
1. **Contain**: revoke the suspicious sessions and tokens immediately (forcing re-authentication) and withdraw on-behalf-of delegations.
2. **Scope**: look for cross-tenant or IDOR access in the same principal's recent verdicts (`/v1/findings?…`) and approval records.
3. **Eradicate**: run the role and permission inventory (D5-07) and remove excess privileges.
4. **Evidence**: export the signed bundle for the incident window — if personal data was accessed, run the D2 runbook alongside.
