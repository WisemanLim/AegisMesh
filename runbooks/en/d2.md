# Runbook — D2 data leakage incident
1. **Contain**: set the output gate to `enforce`; for regulated-kr, confirm the D2-01 threshold 0.6 policy.
2. **Confirm the leak**: for credentials, revoke and reissue immediately (dynamic secrets). For personal data, settle the number of data subjects and the fields involved.
3. **Notification decision**: PIPA §34 (breach notification) and §34-2 — needs legal review (design reference, not legal advice).
4. **Evidence**: export the signed bundle for the incident window — raw content is not retained (NFR-D1), so only verdicts, reasons and locations remain.
5. **Eradicate**: inspect the log pipeline (D2-06) and run the deletion-propagation audit (D2-07).
