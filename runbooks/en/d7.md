# Runbook — D7 supply chain incident
1. **Contain**: confirm that the quarantine entries created by continuous checks (`/v1/quarantine`) are active — the tool gate blocks them immediately.
2. **Blast radius**: find the agents and targets that use the affected MCP server, package or model (agent and tool names in the verdict search).
3. **Eradicate**: roll back to a pinned version, re-verify signatures and hashes, then re-register (R1–R5).
4. **Release**: only after eradication is confirmed, `POST /v1/quarantine/{id}:release` (the principal is recorded).
