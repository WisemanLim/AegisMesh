# Runbook — D9 infrastructure compromise incident
1. **Isolate**: disconnect the compromised host from the network and revoke its credentials.
2. **Preserve**: keep runtime events and disk snapshots (forensics).
3. **Eradicate**: rebuild images (signature-verified), re-apply IaC, close exposed ports.
4. **Recover**: return to service only after the integrity check (D9-02) passes.
