# 런북 — D1 프롬프트 인젝션 사건
1. **봉쇄**: 해당 대상의 입력 관문 단계를 `enforce` 로 올린다(`POST /v1/profiles/{id}:apply`, stage=enforce). 오염 출처(도메인·문서)를 허용목록에서 제외한다.
2. **범위 확인**: 사건의 traceId 로 `/v1/findings?trace=` 조회 → 같은 출처에서 들어온 다른 요청을 찾는다.
3. **근절**: 오염 문서를 색인·메모리에서 제거하고 D8-03 재스캔(`POST /v1/scan`)을 돌린다.
4. **증적**: `/v1/evidence:export` 로 사건 구간 서명 묶음을 내보내고 `python -m aegis verify-bundle` 로 검증한다.
5. **복구·회고**: 공격 입력을 해당 에이전트 `tests/attacks/` 에 추가하고 기준선을 갱신한다(NFR-Q5).
